# مُضيف: منصة إدارة حجوزات الغرف والاستوديوهات

منصة ويب عربية يدير فيها أصحاب الغرف والاستوديوهات حجوزاتهم من Airbnb وBooking.com وجاذر إن في مكان واحد.

## المزايا

- **حسابات مستقلة لكل مالك**: كل مالك يرى وحداته وحجوزاته فقط.
- **الوحدات**: إضافة الغرف والاستوديوهات مع سعر الليلة وسعر الخميس والجمعة.
- **الحجوزات**: تسجيل الحجز المباشر، حساب السعر تلقائياً، عمولة كل منصة، المدفوع والمتبقي، ورابط واتساب للضيف.
- **منع الحجز المزدوج**: النظام يرفض أي حجز يتداخل مع حجز آخر، وإذا جاء التعارض من المنصات يظهر تنبيه أحمر.
- **التقويم الموحد**: كل الوحدات في شاشة واحدة، ولون لكل منصة.
- **الربط مع المنصات عبر iCal**: استيراد حجوزات كل منصة، وإعطاء كل منصة رابطاً يغلق التواريخ المحجوزة من غيرها. المزامنة تلقائية كل 15 دقيقة.
- **التقارير**: الإيراد الصافي بعد العمولات، المصاريف، صافي الربح، الإشغال، متوسط سعر الليلة، حسب الشهر والمنصة والوحدة.
- **لوحة اليوم**: حالة كل وحدة الآن، الوصول والمغادرة بأزرار تسجيل الدخول والخروج، المبالغ غير المحصلة، المهام، ومقارنة بالشهر الماضي.
- **إدارة الحجز**: تسجيل دخول وخروج (ومبكر)، لم يحضر، إلغاء بسبب واستعادة، دفعات واسترجاع بطرق دفع مختلفة، فاتورة للطباعة مع الضريبة، ورسائل واتساب جاهزة.
- **الضيوف**: سجل لكل ضيف مع إقاماته، وقائمة حظر تنبه عند الحجز.
- **المصاريف**: لكل وحدة أو عامة، بالبنود، وتُخصم من الربح.
- **التنظيف والمهام**: مهمة تنظيف تلقائية يوم كل خروج، وتعيين العامل، وأجرة التنظيف تُسجل كمصروف تلقائياً.
- **الأسعار والمواسم**: أسعار خاصة لفترات (موسم الحج، الإجازات) مع حد أدنى لليالي، ويحسبها النظام في كل حجز.
- **إغلاق التواريخ**: للصيانة أو الاستخدام الشخصي، وتظهر محجوزة في كل المنصات.
- **التصدير**: الحجوزات والمصاريف والضيوف والتقارير إلى Excel.
- **الإعدادات**: بيانات النشاط والرقم الضريبي، نصوص الرسائل، تغيير كلمة المرور.
- **الفريق والصلاحيات**: مالك، مدير، عامل نظافة. العامل يدخل بحسابه ويشوف مهامه فقط من جواله.
- **سجل النشاط**: كل تعديل على الحجوزات والدفعات ومن سوّاه.
- **صور وتفاصيل الوحدة**: صور، وصف، مرافق، قوانين السكن، الواي فاي، رابط الموقع.
- **صفحة الحجز المباشر**: رابط عام (`/book/اسمك`) يحجز منه الضيف بدون عمولة، والطلب يوصلك للتأكيد أو الرفض.
- **صفحة الضيف**: رابط خاص لكل حجز فيه التفاصيل وتعليمات الدخول (تظهر قبل الوصول بيوم)، وتسجيل بيانات الهوية، والتقييم بعد المغادرة.
- **رسوم وخصومات** على الحجز تظهر في الفاتورة، و**مبلغ التأمين** مع إرجاعه كاملاً أو جزئياً.
- **جدول دفعات** للإقامات الشهرية مع تنبيه الأقساط المتأخرة.
- **الملاك وكشوف الحساب**: لشركات إدارة الأملاك، نسبة إدارة لكل مالك وكشف شهري بالمستحقات وتسجيل التحويل.
- **مصاريف شهرية ثابتة** تُسجل تلقائياً.
- **بحث شامل** بالاسم والجوال ورقم الحجز ورقم الهوية.
- **تطبيق على الجوال**: افتح المنصة من متصفح الجوال واختر "إضافة إلى الشاشة الرئيسية".
- **نسخ احتياطي** لقاعدة البيانات من الإعدادات.

## التقنيات

Next.js 15 + React 19 + SQLite (better-sqlite3) + Tailwind CSS. قاعدة البيانات ملف واحد في `data/mudeef.db`، فلا تحتاج خادم قاعدة بيانات منفصل.

## التشغيل على جهازك

```bash
npm install
npm run dev
# افتح http://localhost:3000
```

بيانات تجريبية (بعد تشغيل المنصة مرة واحدة). تنشئ أيضاً حساب عامل نظافة `cleaner@mudeef.sa` ومدير `manager@mudeef.sa` بنفس كلمة المرور، وصفحة حجز على `/book/rawda`:

```bash
npm run seed
# الدخول: demo@mudeef.sa / demo1234
```

## النشر على سيرفر Hostinger (VPS)

### 1. تجهيز السيرفر (مرة واحدة)

```bash
ssh root@IP_السيرفر
apt update && apt install -y nginx sqlite3 build-essential python3 git
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
npm install -g pm2
```

### 2. رفع المشروع

```bash
mkdir -p /var/www && cd /var/www
git clone https://github.com/USERNAME/mudeef.git
cd mudeef
cp .env.example .env
nano .env    # عدّل APP_URL وضع قيمة SESSION_SECRET
```

لتوليد مفتاح الجلسات:

```bash
openssl rand -base64 48
```

### 3. البناء والتشغيل

```bash
npm ci
npm run build
pm2 start ecosystem.config.js
pm2 save
pm2 startup    # نفّذ الأمر الذي يطبعه حتى تعمل المنصة بعد إعادة تشغيل السيرفر
```

### 4. الدومين وشهادة HTTPS

اربط الدومين (أو subdomain) بعنوان السيرفر من لوحة Hostinger (سجل A)، ثم:

```bash
cp deploy/nginx-mudeef.conf /etc/nginx/sites-available/mudeef
nano /etc/nginx/sites-available/mudeef   # غيّر mudeef.example.com إلى دومينك
ln -s /etc/nginx/sites-available/mudeef /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

apt install -y certbot python3-certbot-nginx
certbot --nginx -d دومينك
```

**مهم:** روابط iCal يجب أن تكون على HTTPS ودومين حقيقي، لأن Airbnb وBooking.com يرفضان الروابط المحلية.

### 5. النسخ الاحتياطي اليومي

```bash
chmod +x deploy/backup.sh
crontab -e
# أضف السطر:
0 3 * * * /var/www/mudeef/deploy/backup.sh
```

### التحديث لاحقاً

من مجلد المشروع على السيرفر:

```bash
bash deploy/update.sh
```

يأخذ نسخة احتياطية من قاعدة البيانات، ويسحب آخر نسخة من GitHub، ويبني ويعيد التشغيل. قاعدة البيانات تتحدث تلقائياً بدون ما تفقد بياناتك.

### بديل: Docker

إذا كان Docker مثبتاً على السيرفر:

```bash
cp .env.example .env && nano .env
docker compose up -d --build
```

## كيف يربط المالك وحدته مع منصة

1. من صفحة الوحدة يلصق رابط تقويم المنصة (iCal export) في خانة الاستيراد.
2. ينسخ رابط مُضيف الخاص بتلك المنصة ويلصقه في خانة استيراد التقويم عندها.
3. يكرر ذلك لكل منصة. أي حجز في منصة يُغلق تلقائياً في البقية.

رابط التصدير لكل منصة لا يحتوي على حجوزاتها هي، حتى لا تغلق تواريخها مرتين، ولا يحتوي على أي بيانات للضيوف.

## حدود ربط iCal

- ينقل التواريخ فقط، لا الأسعار ولا الرسائل ولا اسم الضيف.
- المنصات تقرأ التقويم كل ساعة تقريباً، فيبقى احتمال صغير لحجز مزدوج في الدقائق الأولى. المنصة تنبهك فوراً إذا حصل.

## المرحلة القادمة

- الربط الرسمي عبر API مع Booking.com ثم Airbnb (برامج الشركاء).
- التواصل مع جاذر إن لربط مباشر.
- فواتير إلكترونية متوافقة مع هيئة الزكاة (فاتورة).
- مهام التنظيف لعمال النظافة، والرسائل التلقائية للضيوف.
- صفحة حجز مباشر لكل مالك مع الدفع الإلكتروني.
- مستخدمين متعددين بصلاحيات (مالك، مدير، عامل نظافة).

## هيكل المشروع

```
app/
  (auth)/          تسجيل الدخول وإنشاء الحساب
  (app)/           صفحات المنصة: اليوم، التقويم، الحجوزات، الوحدات، الربط، التقارير
  api/ical/        روابط iCal التي تقرأها المنصات
  api/cron/sync/   تشغيل المزامنة من الخارج (اختياري)
components/        مكونات الواجهة
lib/
  db.js            قاعدة البيانات والجداول
  actions.js       كل عمليات الحفظ والتعديل
  ical.js          استيراد وتصدير التقويمات
  queries.js       استعلامات الصفحات والتقارير
instrumentation.js المزامنة التلقائية في الخلفية
deploy/            ملفات النشر (nginx، النسخ الاحتياطي)
```
